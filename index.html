📖 코딩 몰라도 되는 4단계 연결 요약

① 무료 Gemini API 키 → 스크립트 속성에 등록 (1분) Google AI Studio에서 발급받은 키를 복사 → Apps Script 왼쪽 메뉴 [프로젝트 설정(⚙️)] → 맨 아래 [스크립트 속성 추가] 클릭 → 속성 이름에 GEMINI_API_KEY, 값에 복사한 키를 넣고 저장! (코드에 키가 남지 않아 GitHub에 올려도 안전합니다)
② 사장님 · 스태프 이메일 등록 Code.gs 맨 위 ALLOWED_EMAILS에 사장님과 스태프의 @gmail.com 주소를 적어주세요. (여기에 적힌 사람만 접속됩니다)
③ 구글 시트에 Code.gs 붙이고 웹 앱 배포 「윤슬향방 매출 장부」 시트 상단 메뉴 [확장 프로그램] → [Apps Script] 클릭 → Code.gs 내용 붙여넣기 → 우측 상단 [배포] → [새 배포] → 유형: 웹 앱, 다음 사용자로 실행: 나, 액세스 권한: 모든 사용자로 배포 후 나온 웹 앱 URL을 위 1번 칸에 붙여넣기!
④ 구글 로그인 버튼용 클라이언트 ID 발급 Google Cloud Console → [API 및 서비스] → [사용자 인증 정보] → [+ 사용자 인증 정보 만들기] → OAuth 클라이언트 ID (웹 애플리케이션) 선택 → [승인된 자바스크립트 원본]에 Vercel 주소(예: https://내주소.vercel.app) 추가 후 발급된 클라이언트 ID를 위 2번 칸에 붙여넣기!
